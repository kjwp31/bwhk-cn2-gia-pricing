## 这么贵到底贵在哪

贵在线路，不在配置。同样的 2核2GB，一台普通美国 VPS 年付可能不到 $30，香港这里要 $899.99，差出来的全是网络成本。

国内访问海外服务器，走的是三种完全不同质量的路：

- **163 骨干（AS4134）**：最普通的线路，便宜，晚高峰丢包率可以超过 30%，开网页都卡；
- **CN2 GT**：电信精品网的过渡层，2019 年之后也开始拥堵，官方自己承认体验“基本和 163 一样堵”；
- **CN2 GIA**：专线级别，从机房出口到国内全程走电信精品网，抗拥堵能力最强。这条线路的 IP 转发成本能到每 Mbps 120 美元，1Gbps 满带宽跑一个月，光线路账单就可能是 10 万美元级别。

香港机房的特殊性在于它同时占了两样东西：离大陆最近的物理距离，和最好的线路。实际表现上，广东延迟 9ms 上下，华东约 30–40ms，联通方向丢包接近零。有第三方测评记录显示这一档机器用的是 AMD EPYC 处理器，磁盘顺序读写能到 900MB/s 左右，性能本身不是短板。
